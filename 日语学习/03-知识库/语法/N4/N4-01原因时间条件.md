# N4-01 原因、时间与条件

## 原因、转折与并列

| 句型       | 接续／意义与限制                    | 例句                                                                                                                                |
| -------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| ～ので      | `V／イA普通形；ナA／N＋な`；客观、委婉原因    | 雨が降っているので、出かけません。／因为在下雨，不出门。<br>このかばんは重いので、持てません。／因为这个包很重，拿不动。<br>静かなので、ここで勉強します。／因为很安静，在这里学习。<br>今日は休みなので、学校へ行きません。／因为今天休息，不去学校。 |
| ～から      | 普通形／礼貌形均可；主观判断，后可接意志命令      | 寒いから、窓を閉めてください。／因为冷，请关窗。<br>明日試験があるから、勉強します。／因为明天有考试，所以学习。<br>危ないですから、触らないでください。／因为危险，请不要碰。                                       |
| ～て／～なくて  | 原因；后项多为无意志结果、感情或状态          | 財布をなくして困っています。／丢了钱包，很为难。<br>熱があって、学校を休みました。／因为发烧，请假没去学校。<br>お金がなくて、困っています。／因为没有钱，很为难。                                             |
| ～のに      | `V／イA普通形；ナA／N＋な`；与预期相反，“明明” | 薬を飲んだのに、まだ熱があります。／明明吃药了还发烧。<br>安いのに、おいしいです。／明明便宜却很好吃。<br>便利なのに、あまり使いません。／明明方便却不太使用。<br>日曜日なのに、仕事があります。／明明是星期日却有工作。                |
| ～が／～けれども | 转折或铺垫；けど更口语                 | この部屋は狭いですが、明るいです。／房间虽小但明亮。<br>行きたいけれども、時間がありません。／想去但是没有时间。                                                                        |
| ～し、～し    | 普通形；并列多个理由／优点，暗示还有其他        | この店は安いし、おいしいし、よく来ます。／这店又便宜又好吃，所以常来。<br>今日は雨だし、風も強いし、出かけません。／今天又下雨风又大，所以不出门。                                                       |
| ～たり～たり   | Vた形；列举不完全、动作无固定顺序           | 週末は本を読んだり料理を作ったりします。／周末读书做饭等。<br>休みの日は映画を見たり、買い物をしたりします。／休息日看看电影、买买东西等。                                                           |
| ～か～か     | 嵌入疑问“是 A 还是 B”              | 行くか行かないか、今日決めます。／今天决定去不去。<br>電車かバスか、まだ分かりません。／还不知道是电车还是公交车。                                                                       |

## 时间关系

| 句型      | 接续／意义与限制                             | 例句                                                                                                                                                                                                           |
| ------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ～時      | `V普通形／イA／ナAな／Nの＋時`；主句动作的时间           | 日本へ行く時、かばんを買った。／去日本前买了包。<br>忙しい時、音楽を聞きます。／忙的时候听音乐。<br>暇な時、映画を見ます。／闲的时候看电影。<br>子どもの時、よくここで遊びました。／小时候经常在这里玩。                                                                                                   |
| Vる時／Vた時 | Vる时从句动作尚未完成；Vた时已经完成                  | 家を出る時、鍵をかける。／出门时锁门。<br>家に帰った時、電話した。／回家后打了电话。                                                                                                                                                                 |
| ～間      | `Vている／Nの＋間`；整个期间持续                   | 夏休みの間、毎日働きました。／整个暑假每天工作。<br>母が料理をしている間、私は宿題をしました。／妈妈做饭期间，我做了作业。                                                                                                                                              |
| ～間に     | 某段期间内发生一次／完成                         | 留守の間に、荷物が届きました。／不在家期间包裹到了。<br>夏休みの間に、京都へ行きたいです。／想在暑假期间去京都。                                                                                                                                                   |
| ～うちに    | `V辞書／ない／ている、イA、ナAな、Nの`；趁状态未变／变化中不知不觉 | 日本にいるうちに、富士山を見たいです。／想趁在日本时看看富士山。<br>忘れないうちに、メモしてください。／请趁没忘记前记下来。<br>日本に住んでいるうちに、日本語を上達させたいです。／想趁住在日本时提高日语水平。<br>若いうちに、いろいろ経験したいです。／想趁年轻经历各种事情。<br>静かなうちに、仕事を終わらせます。／趁安静时完成工作。<br>学生のうちに、たくさん勉強します。／趁学生时代多学习。 |
| ～前に     | `V辞書／Nの／数量词＋前に`                      | 会議の前に資料を読みます。／会前读资料。<br>寝る前に、歯を磨きます。／睡前刷牙。<br>三日前に日本へ来ました。／三天前来到了日本。                                                                                                                                         |
| ～た後で    | `Vた／Nの＋後で`；A 后 B，不强调紧接               | 食事をした後で散歩しました。／饭后散步。<br>授業の後で、先生に質問しました。／课后向老师提问。                                                                                                                                                            |
| ～てから    | Vて；A 完成后才 B，顺序强                      | 日本へ来てから、日本語を始めた。／来日本后才开始学日语。<br>手を洗ってから、ご飯を食べます。／洗手后吃饭。                                                                                                                                                      |
| ～ところだ   | V辞书＝正要；Vている＝正在；Vた＝刚刚                 | 今から出かけるところです。／正要出门。<br>今、昼ご飯を食べているところです。／现在正在吃午饭。<br>今、帰ってきたところです。／刚刚回来。                                                                                                                                     |
| ～たばかり   | Vた；刚做完；说话人主观觉得时间短                    | 日本に来たばかりです。／刚来日本。<br>さっき昼ご飯を食べたばかりです。／刚刚吃完午饭。                                                                                                                                                                |
| ～までに    | `V辞書／N＋までに`；截止点前完成；区别持续终点「まで」        | 金曜日までにレポートを出してください。／请在周五前提交报告。<br>九時までに来てください。／请在九点前来。                                                                                                                                                       |

## 四种条件

| 句型       | 接续／意义与限制                                  | 例句                                                                                                                               |
| -------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ～と       | `V辞書／ない`；恒常、机械结果、发现；后项一般不用意志命令            | 春になると、桜が咲きます。／一到春天樱花就开。<br>このボタンを押すと、ドアが開きます。／按这个按钮门就会开。<br>薬を飲まないと、病気が治りません。／不吃药病就不会好。                                          |
| ～ば       | `Vば`；イA `い→ければ`；ナA／N `なら（ば）`；一般条件，后项意志受限制 | 安ければ買います。／便宜就买。<br>時間があれば、手伝います。／有时间就帮忙。<br>天気がよければ、出かけます。／天气好的话就出门。<br>静かなら、ここで勉強できます。／安静的话可以在这里学习。<br>学生なら、割引があります。／如果是学生，有折扣。 |
| ～たら      | 四类谓语た形＋ら；假定、确定先后，限制最少                     | 駅に着いたら、電話してください。／到站后请打电话。<br>暇だったら、遊びに来てください。／有空的话请来玩。<br>安かったら、買います。／便宜的话就买。<br>学生だったら、割引があります。／如果是学生，有折扣。                      |
| ～なら      | 普通形＋なら；承接话题／以所获信息为条件                      | 京都へ行くなら、秋がいいです。／若去京都，秋天好。<br>静かなら、この部屋を使いましょう。／如果安静，就用这个房间吧。<br>学生なら、このカードが必要です。／如果是学生，需要这张卡。                                    |
| ～ても      | `Vて／イAくて／ナA・Nでも`；让步“即使”                   | 忙しくても、朝ご飯は食べます。／再忙也吃早饭。<br>雨が降っても、試合をします。／即使下雨也比赛。<br>高くても、買いたいです。／即使贵也想买。<br>便利でも、使いません。／即使方便也不用。<br>休みでも、働きます。／即使休息日也工作。       |
| もし～たら／なら | 「もし」加强假设，不与确定事实搭配                         | もし時間があったら、手伝ってください。／如果有时间请帮忙。<br>もし東京へ行くなら、浅草も見てください。／如果要去东京，也请看看浅草。                                                             |
| ～たらどうですか | `Vた形＋らどうですか`；建议“……如何”                     | 早く病院へ行ったらどうですか。／早点去医院如何？<br>少し休んだらどうですか。／稍微休息一下如何？                                                                               |
