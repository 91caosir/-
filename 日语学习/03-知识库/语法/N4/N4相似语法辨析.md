# N4相似语法辨析

| 对比 | 判断标准 | 对比例 |
|---|---|---|
| から vs ので | から主观、可接命令；ので客观委婉 | 寒いから閉めて。／寒いので閉めました。 |
| と vs ば vs たら vs なら | と规律；ば一般条件；たら最自由／先后；なら承接话题 | 春になると咲く。／安ければ買う。／着いたら電話して。／行くなら秋がいい。 |
| 間 vs 間に | 間后项持续；間に后项一次发生或完成 | 留守の間、雨だった。／留守の間に荷物が来た。 |
| ている vs てある | 前者状态／进行；后者他动词有意结果 | 窓が開いている。／窓が開けてある。 |
| ておく vs てある | ておく说准备动作；てある说准备后的状态 | 資料を置いておく。／資料が置いてある。 |
| そうだ两义 | 样态接词干、靠观察；传闻接普通形、靠消息 | 降りそうだ。／降るそうだ。 |
| ようだ vs みたいだ vs らしい | ようだ中性判断；みたい口语；らしい依传闻或典型性 | 留守のようだ。／夢みたいだ。／彼らしい答えだ。 |
| ように vs ために | 非意志能力／避免用ように；明确意志目的用ために | 見えるように前へ。／見るために前へ。 |
| だけ vs しか～ない | だけ中性；しか必须否定并强调不足／唯一 | 一つだけある。／一つしかない。 |
| たところ vs たばかり | ところ是客观“刚刚那一刻”；ばかり是主观时间短 | 今着いたところ。／先月来たばかり。 |
| てくれる vs てもらう | 前者以给予者为主语；后者以受益者为主语 | 友達が直してくれた。／友達に直してもらった。 |
| 可能形 vs 見える／聞こえる | 可能形是有意能力；后者自然可见可闻 | 字が読める。／山が見える。 |
