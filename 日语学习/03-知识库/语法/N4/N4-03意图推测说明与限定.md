# N4-03 意图、推测、说明与限定

## 意图、计划与建议

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| V意向形 | 当场意志／提议；礼貌形「ましょう」 | もう帰ろう。／回去吧。 |
| V意向形＋と思う | 想要／打算做，尚未完全确定 | 来年留学しようと思っています。／打算明年留学。 |
| V辞书／ない＋つもり | 明确打算；也可表“自认为” | 車は買わないつもりです。／不打算买车。 |
| V辞书／Nの＋予定 | 客观安排、日程 | 会議は三時に始まる予定です。／会议预定三点开始。 |
| Vた＋ほうがいい | 最好做；建议较直接 | 疲れているなら、休んだほうがいい。／累了最好休息。 |
| Vない＋ほうがいい | 最好别做 | 夜遅くコーヒーを飲まないほうがいい。／深夜最好别喝咖啡。 |
| V辞书＋な | 强禁止 | ここに入るな。／不准进入。 |
| V命令形 | 强命令；日常慎用 | 早く来い。／快来。 |

## 推测、样态与传闻

| 句型 | 接续／意义与限制 | 例句 |
|---|---|---|
| ～だろう／でしょう | 普通形；推测或征求确认 | 明日は晴れるでしょう。／明天大概晴。 |
| ～かもしれない | 普通形，N／ナA肯定不加「だ」；可能性较低 | 彼は来ないかもしれません。／他可能不来。 |
| ～はずだ | `V／イA普通形；ナAな；Nの`；基于根据理应 | 田中さんはもう着いたはずです。／田中应该已经到了。 |
| ～そうだ（样态） | `Vます；イA去い；ナA词干`；眼前迹象“看起来” | 雨が降りそうです。この料理はおいしそうです。／像要下雨；菜看起来好吃。 |
| ～なさそうだ | Vない→なさそう；イA否定多为「くなさそう」 | 彼は来なさそうです。／他看样子不会来。 |
| ～そうだ（传闻） | 四类普通形原样接；“听说” | 天気予報によると、明日は雨だそうです。／据预报说明天下雨。 |
| ～ようだ | `V／イA普通形；ナAな；Nの`；依据判断“似乎” | 外は寒いようです。／外面似乎很冷。 |
| ～みたいだ | 普通形；口语“好像／像” | あの人は先生みたいです。／那人好像是老师。 |
| ～らしい | 普通形；传闻或典型特征 | 田中さんは来月結婚するらしい。／听说田中下月结婚。 |

## 说明、引用与嵌入疑问

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| ～んです／のです | `V／イA普通形；ナA／Nな`；解释背景、要求说明 | 実は、来週引っ越すんです。／其实下周搬家。 |
| ～と言っていた | 转述某人曾说 | 母は遅くなると言っていました。／妈妈说会晚。 |
| ～と思っている | 持续的想法／计划；第三人称也可 | 父はこの町が安全だと思っています。／父亲认为这城安全。 |
| 疑问词＋普通形＋か | 嵌入疑问；句中不倒装 | 駅がどこにあるか知っていますか。／知道车站在哪吗？ |
| 普通形＋かどうか | 是否 | 明日行けるかどうか分かりません。／不知道明天能否去。 |

## 限定与举例

| 句型 | 接续／意义与限制 | 例句 |
|---|---|---|
| ～だけ | 中性“仅限这些”；可与肯定搭配 | 必要な物だけ買いました。／只买了必需品。 |
| ～しか～ない | “除此之外没有”，必须接否定 | 千円しかありません。／只有一千日元。 |
| ～ばかり | 净是／总是；带说话人评价 | 弟はゲームばかりしています。／弟弟净打游戏。 |
| ～など／なんか | 举例、弱化；なんか口语且可带轻视 | 週末は映画などを見ます。／周末看看电影之类。 |
| Nでも | 举一个轻松例子“比如……” | コーヒーでも飲みませんか。／喝杯咖啡什么的？ |
| Nまで | 连……都；范围终点 | 子どもまで知っています。／连孩子都知道。 |
| Nほど | 程度／比较基准 | 富士山ほど高くありません。／没富士山那么高。 |
| ～か～ | 不定指称 | だれか来ましたか。／有人来过吗？ |
| ～も＋否定 | 全面否定 | どこにも行きませんでした。／哪儿也没去。 |
