# N4-04 授受、敬语、被动与使役

## 授受

| 句型 | 视点与助词 | 例句 |
|---|---|---|
| AはBにNをあげる | A 给 B；B 不能是说话人 | 私は妹に本をあげました。／我给妹妹书。 |
| Aは私／内群にNをくれる | 他人给我方；主语是给予者 | 友達が私に写真をくれました。／朋友给了我照片。 |
| AはBに／からNをもらう | A 从 B 得到；主语是接受者 | 私は先生に辞書をもらいました。／我从老师处得到词典。 |
| Vてあげる | 为别人做；对上级慎用，可能显恩惠 | 私は弟に宿題を教えてあげた。／我教弟弟作业。 |
| Vてくれる | 别人为我方做，含感谢视点 | 友達が駅まで送ってくれた。／朋友送我到车站。 |
| Vてもらう | 请／得到别人为主语做；行动者用「に」 | 私は先生に作文を直してもらった。／请老师改了作文。 |
| Vていただけませんか | 非常委婉的请求 | もう一度説明していただけませんか。／能否请您再说明一次？ |
| Vてくださる | 「てくれる」的尊敬说法 | 先生が推薦状を書いてくださいました。／老师为我写了推荐信。 |
| Vていただく | 「てもらう」的谦让说法 | 先生に作文を見ていただきました。／承蒙老师看了作文。 |

## 可能、自动词与他动词

| 句型 | 变形／意义 | 例句 |
|---|---|---|
| V可能形 | 五段う→え段＋る；一段去る＋られる；する→できる；来る→来られる | 私は漢字が読めます。／我会读汉字。 |
| V辞书＋ことができる | 与可能形近义，略正式 | この図書館で本を借りることができます。／可在此借书。 |
| Nが見える／聞こえる | 自然进入视听，不是有意能力 | 窓から山が見えます。／从窗户能看到山。 |
| 自动词 | 变化／状态的主体用「が」 | ドアが開きました。／门开了。 |
| 他动词 | 行为者以「Nを」作用于对象 | 私がドアを開けました。／我打开了门。 |
| 自动词ている | 结果状态 | 電気が消えています。／灯灭着。 |
| 他动词てある | 有意留下的结果 | 電気が消してあります。／灯被预先关好了。 |

## 被动与使役

| 句型 | 变形／格关系 | 例句 |
|---|---|---|
| 直接被动 | 承受者は／が＋施动者に＋V被动 | 私は先生に褒められました。／我被老师表扬了。 |
| 间接／受害被动 | 受影响者は＋施动者に＋对象を＋V被动 | 私は弟にケーキを食べられた。／我的蛋糕被弟弟吃了。 |
| 事物主语被动 | Nは／が＋V被动；施动者常省略 | この寺は千年前に建てられました。／这寺建于千年前。 |
| 使役 | 使役者は＋人に（自动词）／人に对象を（他动词）＋V使役 | 母は子どもに野菜を食べさせます。／母亲让孩子吃菜。 |
| V使役＋てください | 请求允许自己做 | 今日は早く帰らせてください。／请允许我今天早退。 |

## 入门敬语

| 类型 | 形式 | 例句 |
|---|---|---|
| 尊敬语 | お＋Vます＋になる；部分动词用特殊形 | 先生はもうお帰りになりました。／老师已经回去了。 |
| 尊敬被动 | V（ら）れる；语气比专用尊敬语朴素 | 先生は何時に来られますか。／老师几点来？ |
| 谦让语 | お＋Vます＋する；动作涉及尊长 | お荷物をお持ちします。／我来为您拿行李。 |
| 礼貌语 | です／ます／ございます | 受付はこちらでございます。／前台在这边。 |

常见特殊形：いる／行く／来る→いらっしゃる；見る→ご覧になる；言う→おっしゃる；食べる／飲む→召し上がる；する→なさる。谦让：行く／来る→参る；いる→おる；言う→申す／申し上げる；見る→拝見する；食べる／飲む／もらう→いただく；する→いたす。
