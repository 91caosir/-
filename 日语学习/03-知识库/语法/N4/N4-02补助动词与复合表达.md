# N4-02 补助动词与复合表达

## Vて补助表达

| 句型 | 接续／核心语感 | 例句 |
|---|---|---|
| Vている | 进行、结果状态、反复习惯；瞬间动词常表结果 | 結婚しています。毎朝走っています。／已婚；每天晨跑。 |
| Vてある | 他动词て形；人为动作留下、结果有目的地存在 | 机に資料が置いてあります。／资料预先放在桌上。 |
| Vておく | 提前准备；临时处置；口语「とく」 | 旅行の前に切符を買っておきます。／旅行前先买票。 |
| Vてみる | 尝试做 | この靴を履いてみてもいいですか。／能试穿这双鞋吗？ |
| Vてしまう | 完成／遗憾失误；口语「ちゃう／じゃう」 | 宿題をしてしまいました。財布を忘れてしまった。／作业做完了；不小心忘了钱包。 |
| Vていく | 从现在向将来／由近及远的变化、移动后离开 | これから暑くなっていきます。／今后会越来越热。 |
| Vてくる | 从过去到现在／由远及近；做完再回来 | 日本語が分かってきました。／渐渐懂日语了。 |
| Vてほしい | 希望他人做；对象常用「に」 | 先生にもう一度説明してほしいです。／希望老师再讲一次。 |
| Vないでほしい | 希望他人别做 | ここで大声で話さないでほしい。／希望别在这里大声说话。 |
| V辞书＋ことがある | 有时会发生；否定为「Vないことがある」 | 忙しくて朝ご飯を食べないことがあります。／有时忙得不吃早饭。 |

## 复合动词与难易程度

| 句型 | 接续／核心语感 | 例句 |
|---|---|---|
| Vます＋始める | 开始动作／变化 | 雨が降り始めました。／开始下雨了。 |
| Vます＋終わる | 动作做完 | この本を読み終わりました。／读完了这本书。 |
| Vます＋続ける | 持续做 | 三年間勉強し続けました。／连续学了三年。 |
| Vます＋出す | 突然开始、向外 | 子どもが急に泣き出した。／孩子突然哭了。 |
| Vます＋やすい | 容易做／性质易于 | このペンは書きやすいです。／这支笔好写。 |
| Vます＋にくい | 难做／性质不易 | この字は読みにくいです。／这个字难读。 |
| Vます＋すぎる | 过度；イA去い／ナA词干＋すぎる | 昨日は食べすぎました。／昨天吃太多了。 |
| Vます＋方 | 做法；带宾语时常 `NのV方` | この漢字の読み方を教えてください。／请教我这个汉字的读法。 |
| Vます＋ながら | 同一主体同时做；后项为主要动作 | 音楽を聞きながら勉強します。／边听音乐边学习。 |

## 状态、变化与决定

| 句型 | 接续／核心语感 | 例句 |
|---|---|---|
| V辞书／ない＋ようになる | 能力、习惯或状况逐渐变化 | 日本語が話せるようになりました。／变得会说日语了。 |
| V辞书／ない＋ようにする | 有意识地努力养成／避免 | 毎日日本語を読むようにしています。／坚持每天读日语。 |
| V辞书／ない＋ことになる | 外部决定／自然结果 | 来月大阪へ転勤することになりました。／决定下月调往大阪。 |
| V辞书／ない＋ことにする | 说话人决定 | 今夜は早く寝ることにします。／决定今晚早睡。 |
| Vた＋まま | 做完后状态不变；Nのまま | 電気をつけたまま寝ました。／开着灯睡了。 |
| Vない＋まま | 未做某事而保持状态 | 朝ご飯を食べないまま出かけた。／没吃早饭就出门。 |
| ～く／にする | 人为改变；也表选择 | 部屋をきれいにしました。／把房间弄干净了。 |
| ～く／になる | 自然变化、成为 | 日が長くなりました。／白天变长了。 |

## 目的

| 句型 | 接续／核心语感 | 例句 |
|---|---|---|
| V辞书／Nの＋ために | 意志动词目的；前后主体通常相同 | 留学するために、お金をためています。／为留学攒钱。 |
| V辞书／ない／可能形＋ように | 以能力、状态或避免为目标 | 忘れないように、メモします。／为了不忘记而记下来。 |
| V辞书＋のに | 用途／评价基准，“用于……／做……方面” | このはさみは紙を切るのに便利です。／这剪刀剪纸方便。 |

## 愿望与感官

| 句型 | 接续／核心语感 | 例句 |
|---|---|---|
| Vます＋たがる | 第三人称显露出的愿望；按一类动词活用 | 弟は日本へ行きたがっています。／弟弟很想去日本。 |
| Nがする | 声、味、气味、感觉 | 外で大きな音がします。／外面有很大的声音。 |
| V普通形＋のが見える／聞こえる | 看见／听见某动作发生 | 子どもが走っているのが見えます。／能看见孩子在跑。 |
| ～ような気がする | `V／イA普通形；ナAな；Nの`；觉得似乎 | 前にもここへ来たような気がします。／感觉以前来过这里。 |
