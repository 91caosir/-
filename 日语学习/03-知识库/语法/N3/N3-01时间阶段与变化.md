# N3-01 时间、阶段与变化

## 时间点与期间

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～うちに | `V辞书／ない／ている；イA；ナAな；Nの`；趁未变化／过程中自然变化 | 忘れないうちにメモしてください。／趁没忘记请记下来。 |
| ～間／間に | 同上；間＝全程持续，間に＝期间内一次完成 | 留学している間に、各地を旅行した。／留学期间游历了各地。 |
| ～最中に／最中だ | `Vている／Nの`；正值动作高潮，常发生意外插入 | 会議の最中に電話が鳴った。／会议正中电话响了。 |
| ～際（に） | `V辞书／た；Nの`；正式“在……之际” | 入国の際、パスポートを見せてください。／入境时请出示护照。 |
| ～たびに | `V辞书／Nの`；每当 A 总会 B | この歌を聞くたびに、故郷を思い出す。／每次听都想起故乡。 |
| ～につけ | V辞书；每当看到／听到就产生感情，搭配有限 | この写真を見るにつけ、学生時代を思い出す。／每看这照片就想起学生时代。 |
| ～以来 | `Vて／N`；自某时起一直到现在 | 卒業して以来、先生に会っていない。／毕业后一直没见老师。 |
| ～て以来 | 强调起点后的持续状态 | 日本に来て以来、毎日日記を書いている。／来日后一直写日记。 |
| ～ぶり（に） | 时间＋ぶり；时隔……再次 | 三年ぶりに友達に会った。／时隔三年见到朋友。 |
| ～中／中に | N＋中；整个期间／期间内 | 夏休み中にこの本を読みます。／暑假内读完这书。 |

## 紧接、先后与机会

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～たとたん（に） | Vた；刚 A 就发生意外 B；后项不能是意志 | 外に出たとたん、雨が降り出した。／刚出门就下雨。 |
| ～かと思うと／かと思ったら | Vた；刚……就……，变化快，主体通常非说话人意志 | 赤ちゃんは泣いたかと思うと、すぐ笑った。／婴儿刚哭又笑。 |
| ～次第 | `Vます`；一……立即……，正式，后项为意志行动 | 駅に着き次第、連絡します。／一到站就联系。 |
| ～て初めて | 做 A 后才首次认识／实现 B | 病気になって初めて、健康の大切さが分かった。／生病后才懂健康重要。 |
| ～上で | `Vた／Nの`＝做 A 后再 B；`V辞书＋上で`＝在做……方面 | よく考えた上で、返事します。／仔细考虑后答复。 |
| ～ついでに | `V辞书／た；Nの`；利用做 A 的机会顺便 B | 銀行へ行くついでに、切手を買った。／去银行顺便买邮票。 |
| ～ところに／へ／を | 正当某阶段时发生插入／被看到 | 出かけようとしたところに、客が来た。／正要出门时来客了。 |
| ～ところだった | 差点就……；常与「もう少しで」 | もう少しで電車に乗り遅れるところだった。／差点误车。 |
| ～途中（で／に） | `V辞书／Nの`；做事或路程中途 | 帰る途中で雨に降られた。／回家途中遇上雨。 |
| ～とおり（に） | `V辞书／た；Nの`；按照／正如 | 説明書に書いてあるとおりに操作した。／按说明书操作。 |
| ～た結果 | Vた／Nの；做 A 后得到客观结果 | 話し合った結果、計画を変更した。／商谈后决定改变计划。 |
| ～ようとする | V意向形；正要／尝试做 | 家を出ようとした時、電話が鳴った。／正要出门时电话响了。 |
| ～ようとしない | 明明该做却没有尝试／意愿 | 何度説明しても、彼は聞こうとしない。／讲多少次他都不肯听。 |

## 变化与进程

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| ～ようになる | V辞书／ない；能力、习惯、状态变化 | 辛い物が食べられるようになった。／变得能吃辣了。 |
| ～ようにする | V辞书／ない；持续努力、规章要求 | 忘れ物をしないようにしてください。／请注意别落东西。 |
| ～ことになる | 外部决定／逻辑结果 | 来月から新しい部署で働くことになった。／决定下月去新部门。 |
| ～ことになっている | 规定、预定或社会惯例 | この寮では十時に門が閉まることになっている。／宿舍规定十点关门。 |
| ～ことにする | 自己决定；`ことにしている`为个人习惯 | 毎朝歩くことにしています。／我规定自己每天晨走。 |
| ～つつある | `Vます`；正在持续变化，书面 | 景気は少しずつ回復しつつある。／经济正在逐渐复苏。 |
| ～一方だ | V辞书；某趋势单向持续，多用于不良变化 | 物価は上がる一方だ。／物价不断上涨。 |
| ～ていく／てくる | 从基准点向未来／从过去到现在的发展 | 利用者はこれから増えていくだろう。／用户今后会增加。 |
| ～ば～ほど | 同一词的ば形＋辞书形；越……越…… | 練習すればするほど上手になります。／越练越熟练。 |
| ～につれて | `V辞书／N`；随 A 渐变，B 也自然渐变 | 年を取るにつれて、時間が早く感じられる。／年纪越大越觉得时间快。 |
| ～にしたがって | `V辞书／N`；随变化／遵从规则，较正式 | 気温が上がるにしたがって、雪が解ける。／随气温上升雪融化。 |
| ～とともに | `V辞书／N`；同时／伴随变化，书面 | 技術の進歩とともに、生活も変わった。／随技术进步生活也变了。 |
| ～に伴って | `V辞书／N`；伴随较大社会性变化 | 人口増加に伴って、住宅が不足した。／随人口增长住宅不足。 |
| ～ごとに | `V辞书／N`；每一次／每个间隔 | この薬は六時間ごとに飲んでください。／请每六小时吃一次药。 |
| ～ずつ | 数量词后；每份相同数量／逐渐 | 毎日十個ずつ単語を覚える。／每天背十个单词。 |
