# N3-02 原因、目的、条件与逆接

## 原因与结果

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～ため（に） | `V／イA普通形；ナAな；Nの`；客观原因，常为负面结果；也表目的 | 大雪のため、電車が止まった。／因大雪电车停运。 |
| ～おかげで | 普通形；N／ナA＋な／である；归功于，正面结果 | 先生のおかげで合格できた。／多亏老师才合格。 |
| ～せいで | 普通形；N／ナA＋な；归咎于，负面结果 | 寝不足のせいで、頭が痛い。／因为睡眠不足头疼。 |
| ～ものだから／もので | 普通形；N／ナA＋な；辩解个人原因，口语 | 道が混んでいたものですから、遅れました。／因为堵车，所以迟到了。 |
| ～ことから | 普通形；从事实得名、推断或成为契机 | 形が星に似ていることから、この名が付いた。／因形似星星而得名。 |
| ～によって | N；原因、手段、施动者或依据 | 台風によって多くの木が倒れた。／因台风许多树倒了。 |
| ～そのため（に） | 承接前句的书面结果 | 電車が止まった。そのため、遅刻した。／电车停运，因此迟到。 |

## 目的、对象与手段

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～ために | V辞书／Nの；意志性目的，前后主体原则上相同 | 研究者になるために、大学院へ進んだ。／为成为研究者读研。 |
| ～ように | V辞书／ない／可能；实现状态、能力或避免 | 後ろの人にも聞こえるように、大きな声で話す。／为让后面人听见而大声说。 |
| ～のに | V辞书；用途、所需评价 | このアプリは単語を覚えるのに役立つ。／此应用有助背单词。 |
| ～によって／により | N；手段、方法，较书面 | インターネットにより申し込めます。／可通过网络申请。 |
| ～を通じて／を通して | N；通过媒介／贯穿整个期间 | 友人を通じてその先生を知った。／通过朋友认识那位老师。 |

## 条件与让步

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～さえ～ば | Nさえ＋条件；只要最低条件成立 | 時間さえあれば、旅行したい。／只要有时间就想旅行。 |
| ～としても | 普通形；即使假定成立也……，书面 | 失敗したとしても、もう一度挑戦する。／即使失败也再挑战。 |
| ～にしても | 普通形／N；即便如此，承认前提后评价 | 買うにしても、まず値段を調べよう。／即使要买也先查价格。 |
| たとえ～ても | て形；无论极端假设如何 | たとえ反対されても、留学します。／即使被反对也留学。 |
| どんなに／いくら～ても | 程度再高也不改变结果 | どんなに忙しくても、連絡してください。／再忙也请联系。 |
| ～ない限り | Vない；只要不……就……／除非 | 努力しない限り、上達しない。／不努力就不会进步。 |
| ～限り（は） | 普通形／Nである；只要某状态持续 | 元気である限り、働きたい。／只要健康就想工作。 |
| ～場合（は） | 普通形；Nの／ナAな；假设场合，客观正式 | 遅れる場合は、連絡してください。／如迟到请联系。 |
| ～たって／だって | ても／でも的口语形式 | 今から急いだって、もう間に合わない。／现在再急也来不及。 |

## 逆接、对照与替代

| 句型 | 接续／语感与限制 | 例句 |
|---|---|---|
| ～ものの | 普通形；N／ナAである；虽承认 A，但 B 不如预期，书面 | 薬を飲んだものの、よくならない。／虽吃了药却没好。 |
| ～ながら（も） | `Vます／イA／ナA词干／N`；虽……却……，书面 | 狭いながらも、快適な部屋だ。／虽小却舒适。 |
| ～くせに | 普通形；N／ナA＋な；明明却，带责备轻蔑 | 知っているくせに、教えてくれない。／明明知道却不告诉我。 |
| ～一方（で） | 普通形；N／ナAである；一方面……另一方面 | 都会は便利な一方、生活費が高い。／城市方便但生活费高。 |
| ～反面 | 普通形；N／ナAである；同一事物相反两面 | この仕事は面白い反面、責任も重い。／工作有趣但责任重。 |
| ～代わりに | `V普通形／Nの`；代替、交换条件、补偿 | 私が料理する代わりに、弟が片付ける。／我做饭，弟弟收拾。 |
| ～に対して | N；对某对象／与前项相对照 | 兄が活発なのに対して、弟は静かだ。／哥哥活泼，弟弟安静。 |
| ～というより | 与其说 A，不如说 B，用后项修正前项 | 彼は親切というより、おせっかいだ。／与其说亲切，不如说爱管闲事。 |
| ～と言っても | 虽说 A，但实际程度没有想象中高 | 料理ができると言っても、簡単な物だけです。／虽说会做饭，也只会简单的。 |
