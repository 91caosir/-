# N3-05 立场、对象、关联与书面连接

## 立场、对象与范围

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| ～にとって | N；从某人／群体立场看 | 留学生にとって、住居探しは重要だ。／对留学生而言找房很重要。 |
| ～として | N；以某身份、资格、立场 | 研究生として大学で学んでいる。／作为研究生在大学学习。 |
| ～に対して | N；动作、态度所针对对象 | お客様に対して失礼な言い方だ。／这是对客人失礼的说法。 |
| ～について | N；关于某主题，一般表达 | 日本の教育について調べています。／正在调查日本教育。 |
| ～に関して | N；关于，较正式；修饰名词用「に関する」 | この問題に関して質問があります。／关于这个问题有疑问。 |
| ～において | N；在时间、地点、领域，书面；连体「における」 | 会議は東京において開催された。／会议在东京举行。 |
| ～によると／によれば | N；消息来源 | 天気予報によると、明日は雪だ。／据天气预报明天下雪。 |
| ～によって | N；手段、原因、依据、施动者；按人而异 | 国によって習慣が違う。／习惯因国家而异。 |
| ～に比べて | N；与……相比 | 去年に比べて、売上が増えた。／比去年销售额增加。 |
| ～に応じて | N；根据变化、要求作相应调整 | 経験に応じて仕事を任せます。／按经验分配工作。 |

## 基准、无关与对应

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| ～によっては | N；在某些情况／对象下会有不同结果 | 人によっては、この薬で眠くなる。／有些人吃这药会困。 |
| ～にかかわらず | N／普通形；不论、不受影响，正式 | 経験の有無にかかわらず応募できます。／无论有无经验都可应聘。 |
| ～を問わず | N；不问、不论，公告式 | 年齢を問わず参加できます。／年龄不限均可参加。 |
| ～によって～ | 对应差异“因……而不同” | 季節によって景色が変わる。／景色随季节而变。 |
| ～に合わせて | N；配合某基准主动调整 | 相手の予定に合わせて日を決めた。／配合对方日程定日期。 |
| ～に代わって | N；代替某人／取代旧事物 | 父に代わって、私が会議に出ます。／我代父亲参会。 |

## 书面连接与篇章关系

| 连接词 | 关系 | 例句 |
|---|---|---|
| つまり | 换言、总结 | 彼は父の兄の子、つまり私のいとこだ。／他是父亲哥哥的孩子，也就是我表哥。 |
| すなわち | 更正式的“即” | 十年、すなわち一世紀の十分の一だ。／十年，即一世纪的十分之一。 |
| そのため | 客观因果 | 大雪になった。そのため、空港が閉鎖された。／下大雪，因此机场关闭。 |
| したがって | 根据前项逻辑推出，正式 | 証拠がない。したがって、断定できない。／没有证据，因此无法断定。 |
| そこで | 出现情况后采取主动对策 | 道に迷った。そこで、警察官に聞いた。／迷路了，于是问警察。 |
| ところが | 实际结果与预期相反 | 簡単だと思った。ところが、とても難しかった。／以为简单，实际很难。 |
| それでも | 尽管前情仍坚持后项 | 雨が強かった。それでも試合は続いた。／雨很大，比赛仍继续。 |
| 一方 | 转换到另一侧面／对比 | 都市の人口が増えた。一方、地方では減っている。／城市人口增，另一方面地方在减。 |
| しかも | 递进添加更惊人的事实 | この店は安い。しかも、おいしい。／这店便宜，而且好吃。 |
| なお | 补充仍需注意的信息，正式 | 受付は終了しました。なお、資料は後日公開します。／报名结束；另，资料日后公开。 |
| ただし | 对前项加条件、例外 | 使用は無料です。ただし、登録が必要です。／免费使用，但须注册。 |
| その上 | 同方向递进 | 駅に近く、その上家賃も安い。／离站近，而且房租便宜。 |

## N3 敬语与请求补充

| 句型 | 语用 | 例句 |
|---|---|---|
| お／ご～ください | 尊敬请求；和语多用お，汉语词多用ご | こちらにお名前をご記入ください。／请在此填写姓名。 |
| お／ご～いただく | 谦让地表示承蒙对方做 | 先生にご説明いただきました。／承蒙老师说明。 |
| ～させていただく | 获得许可并受益地做；不可滥用 | 先に帰らせていただきます。／请允许我先告辞。 |
| ～てもらえませんか | 委婉请求，比「てください」柔和 | 少し静かにしてもらえませんか。／能请您安静些吗？ |
