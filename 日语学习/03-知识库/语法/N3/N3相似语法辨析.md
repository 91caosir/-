# N3相似语法辨析

| 对比 | 核心区别 | 对比例 |
|---|---|---|
| うちに vs 間に | うちに含“状态会变，趁现在”；間に只是时间范围 | 若いうちに旅を。／夏休みの間に旅を。 |
| 最中に vs ところに | 最中强调持续动作正高潮；ところ可对应正要／正在／刚做完 | 会議の最中に電話。／出るところに客。 |
| とたんに vs 次第 | とたん后项意外且非意志；次第后项是计划行动 | 出たとたん雨。／着き次第連絡。 |
| ために vs ように | ために用于可控制意志目的；ように用于能力、状态、避免 | 留学するために貯金。／忘れないようにメモ。 |
| おかげで vs せいで | 正面归功／负面归咎；反讽时可反用 | 助言のおかげで成功。／寝不足のせいで失敗。 |
| ても vs としても | ても一般让步；としても是假设承认，较书面 | 雨でも行く。／失敗したとしても続ける。 |
| のに vs ものの vs くせに | のに一般意外；ものの书面承认；くせに含责备 | 安いのに良い。／買ったものの使わない。／知っているくせに。 |
| わけだ vs はずだ | わけだ是已知事实的自然结论；はずだ是有根据的预期 | 十年住んだ。上手なわけだ。／十年住んだ。上手なはずだ。 |
| わけではない vs ないことはない | 前者部分否定；后者弱肯定但有保留 | 嫌いなわけではない。／食べないことはない。 |
| わけがない vs はずがない | 都表不可能；わけがない主观断言更强，はずがない强调根据 | 彼が盗むわけがない。／鍵があるから入れるはずがない。 |
| べきだ vs ことだ | べき是社会常识／义务、语气强；ことだ是针对个人建议 | 規則は守るべきだ。／上達には練習することだ。 |
| だけ vs にすぎない | だけ中性限定；にすぎない带“程度低、不重要”评价 | 一人だけ来た。／彼は代理にすぎない。 |
| がち vs 気味 vs っぽい | がち反复负面倾向；気味轻微状态；っぽい口语性质／易于 | 遅れがち。／風邪気味。／忘れっぽい。 |
| 向き vs 向け | 向き＝客观适合；向け＝设计时以其为对象 | 初心者向きの本。／初心者向けに作った本。 |
| について vs に関して | 都是关于；に関して更正式，范围也较广 | 歴史について話す。／事件に関して発表する。 |
| にとって vs として | にとって是评价立场；として是身份资格 | 私にとって重要。／代表として参加。 |
| によって vs を通じて | によって指手段／原因等；を通じて强调媒介或全期间 | 法律によって定める。／友人を通じて知る。 |
| につれて vs にしたがって | 都表随变化；前者多自然渐变，后者更正式且也能表遵从 | 成長につれて。／規則にしたがって。 |
