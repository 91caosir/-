# N3-03 判断、传闻、义务与说明

## わけ、はず与结论

| 句型 | 接续／意义与限制 | 例句 |
|---|---|---|
| ～わけだ | `V／イA普通形；ナAな；Nの`；由前情自然得出“难怪／也就是说” | 十年日本にいたのか。日本語が上手なわけだ。／原来待了十年，难怪日语好。 |
| ～わけではない | 同上；部分否定“并非（全部）” | 甘い物が嫌いなわけではない。／并不是讨厌甜食。 |
| ～わけがない | 同上；强烈判断“不可能” | 彼が約束を忘れるわけがない。／他不可能忘约定。 |
| ～わけにはいかない | V辞书／ない；受社会责任约束不能／不能不 | 明日は試験だから、休むわけにはいかない。／明天考试，不能休息。 |
| ～はずだ | `V／イA普通形；ナAな；Nの`；有根据“应该” | 地図では近いから、もう着くはずだ。／按地图很近，应该快到了。 |
| ～はずがない | 有根据判断不可能 | そんな難しい問題が子どもに分かるはずがない。／那么难孩子不可能懂。 |
| ～ということだ | 普通形；传闻“据说”或结论“也就是说” | 中止するということは、参加費も返すということですか。／取消也就是退费吗？ |
| ～ことになる | 从事实推导出的结果 | 毎日一時間なら、一年で三百時間以上勉強することになる。／每天一小时，一年就是三百多小时。 |

## 推测、传闻与风险

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| ～ようだ | 根据感官／情况推断；Nの／ナAな | 部屋の電気が消えている。留守のようだ。／灯关着，似乎不在。 |
| ～らしい | 普通形；间接消息／典型性 | 今年の冬は暖かいらしい。／听说今冬暖和。 |
| ～そうだ（传闻） | 普通形原样接；明确消息来源 | ニュースによると、台風が近づいているそうだ。／据新闻说台风接近。 |
| ～そうだ（样态） | 词干接；基于眼前迹象 | この橋は今にも壊れそうだ。／这桥眼看要坏。 |
| ～とのことだ | 普通形＋とのことだ；正式转达通知 | 会議は三時からとのことです。／通知说会议三点开始。 |
| ～おそれがある | `V辞书／Nの`；有发生坏事的风险，正式 | 大雨で川があふれるおそれがある。／大雨恐致河水泛滥。 |
| ～に違いない | 普通形；N／ナA肯定不加だ；高度确信 | 電気がついているから、彼は家にいるに違いない。／灯亮着，他一定在家。 |
| ～に決まっている | 普通形；N／ナA肯定不加だ；口语强烈断定 | そんな話はうそに決まっている。／那种话肯定是假的。 |

## 义务、建议与不必要

| 句型 | 接续／意义与限制 | 例句 |
|---|---|---|
| ～べきだ | V辞书；する→する／すべき；按常识应该 | 約束は守るべきです。／应该守约。 |
| ～べきではない | 不应该 | 人を外見だけで判断すべきではない。／不应只凭外表评判人。 |
| ～ことだ | V辞书／ない；针对个人的建议 | 上手になりたければ、毎日練習することだ。／想进步就应每天练。 |
| ～ことはない | V辞书；没必要 | まだ時間があるから、急ぐことはない。／还有时间，不必急。 |
| ～しかない | V辞书；除此之外无办法，“只好” | 電車がないので、歩くしかない。／没电车，只好走。 |
| ～ないことはない | Vない；并非不……，但有保留 | 食べられないことはないが、あまり好きではない。／并非不能吃，只是不太喜欢。 |
| ～ずに | Vない去「ない」＋ずに；する→せずに；不做 A 而 B，较书面 | 朝ご飯を食べずに出かけた。／没吃早饭就出门了。 |

## 说明、感叹与回忆

| 句型 | 接续／意义与限制 | 例句 |
|---|---|---|
| ～ものだ | 普通形；常识／感叹／过去习惯 | 子どものころ、よく川で遊んだものだ。／小时候常在河边玩。 |
| ～ものか | 普通形；强烈反问“怎么会／绝不” | 二度とあの店に行くものか。／再也不去那家店。 |
| ～ことか | 普通形；与疑问词呼应，强烈感叹 | 合格の知らせをどんなに待ったことか。／不知多么盼望合格消息。 |
| ～っけ | 普通形；口语回想、确认遗忘信息 | 会議は何時からだっけ。／会议几点来着？ |
| ～という | 名词／普通形＋というN；名称或内容同位 | 「令和」という時代。彼が辞めるという話。／名为令和的时代；他要辞职的消息。 |
| ～って | 口语主题／引用／「という」缩约 | 田中さんって、どんな人？／田中是怎样的人？ |
| ～ふりをする | `V／イA普通形；ナAな；Nの`；假装某状态 | 聞こえないふりをして返事をしなかった。／装作没听见而没回答。 |
| ～ことに | 感情形容词＋ことに；说话人先评价整件事 | 驚いたことに、全員が満点だった。／令人惊讶的是全员满分。 |
