# N3-04 限定、程度、倾向与评价

## 限定与强调

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| ～にすぎない | N／普通形；只不过，客观降低程度 | それはうわさにすぎない。／那只不过是传闻。 |
| ～だけでなく～も | 不仅 A 而且 B，中性 | この町は静かなだけでなく、交通も便利だ。／这城不仅安静，交通也方便。 |
| ～ばかりでなく～も | 同上，较书面 | 国内ばかりでなく、海外でも知られている。／不仅国内，海外也知名。 |
| ～ばかりか | 不仅，甚至出现超预期 B | 彼は謝るばかりか、私を責めた。／他不但不道歉，反而责怪我。 |
| ～こそ | 正是；强烈突出 | 今度こそ合格したい。／这次一定要合格。 |
| ～さえ | 连最低／极端例子都 | 忙しくて、昼ご飯を食べる時間さえない。／忙得连午饭时间都没有。 |
| ～まで | 连预料外对象也 | 彼は私の名前まで忘れた。／他连我的名字都忘了。 |
| ～なんか／なんて | 轻视、谦逊、惊讶或举例，口语 | 私なんかまだ初心者です。／我这种人还只是初学者。 |
| ～ほかない | V辞书；除此无他，较书面 | 結果を待つほかない。／只能等待结果。 |
| ～に限る | V辞书／ない／N；最好不过／限于 | 疲れた時は早く寝るに限る。／累时最好早睡。 |
| ～はもちろん～も | A 自不必说，B 也；B 往往更进一步 | 彼は英語はもちろん、中国語も話せる。／英语自不必说，中文也会。 |

## 程度与数量

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| ～ほど | 程度达到……；也作比较基准 | 立っていられないほど疲れた。／累得站不住。 |
| ～ほど～ない | A 不如 B | 今年は去年ほど暑くない。／今年没去年热。 |
| ～くらい／ぐらい | 大致程度／举最低程度 | 自分の名前ぐらい書けます。／至少会写自己的名字。 |
| ～ば～ほど | 越……越…… | 考えれば考えるほど分からなくなる。／越想越不懂。 |
| ～ばかり | 大约数量／净是；语境决定 | 会場には百人ばかり集まった。／会场约聚百人。 |
| ～だらけ | 满是负面、不理想事物 | この作文は間違いだらけだ。／作文错误百出。 |

## 倾向、感受与外观

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| ～がち | `Vます／N`；容易出现，多负面 | 冬は運動不足になりがちだ。／冬天容易运动不足。 |
| ～気味 | `Vます／N`；稍微有某状态 | 最近少し疲れ気味です。／最近有点疲劳。 |
| ～っぽい | `Vます／N／イA词干`；容易、带某感觉，口语 | 彼は忘れっぽい。／他健忘。 |
| ～らしい | N＋らしい；具有典型特征 | 今日は春らしい暖かさだ。／今天有春天般暖意。 |
| ～ような／ように | 像……一样；Nの／普通形 | 鳥のように空を飛びたい。／想像鸟一样飞。 |
| ～みたいな／みたいに | ような／に的口语形式 | 雪みたいに白い。／像雪一样白。 |
| ～向き | N＋向き；性质适合 | この本は初心者向きです。／此书适合初学者。 |
| ～向け | N＋向け；以某对象为目标设计 | 留学生向けの説明会です。／面向留学生的说明会。 |

## 容易混淆的 Vます 复合形式

| 句型 | 含义 | 例句 |
|---|---|---|
| Vきる | 完全做完／做到极限 | 長い小説を一日で読みきった。／一天读完长篇小说。 |
| Vきれない | 无法完全做完 | 料理が多くて食べきれない。／菜太多吃不完。 |
| Vかける／かけのN | 做到一半／刚开始 | 読みかけの本が机にある。／桌上有本读了一半的书。 |
| V直す | 重新做、纠正 | 間違えたところを書き直してください。／请重写错误处。 |
| V合う | 互相做 | 困った時は助け合いましょう。／困难时互相帮助。 |
| V得る／得ない | 有可能／不可能，书面；`得る`读うる／える | 事故は誰にでも起こり得る。／事故可能发生在任何人身上。 |
| Vたて／VたてのN | 刚做完且保持新鲜状态，搭配有限 | 焼きたてのパンは香りがいい。／刚烤好的面包很香。 |

## 程度造成的结果

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| ～あまり | `V辞书／Nの／ナAな`；因过度 A 导致不寻常结果 B | 緊張のあまり、名前を忘れてしまった。／过度紧张把名字忘了。 |
| まるで～ようだ | まるで＋`V普通形／Nの`＋よう；简直像 | この町はまるで絵のように美しい。／这座城美得像画。 |
