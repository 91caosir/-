# N5-03 描述、时间、数量与复句

## 形容词和名词谓语

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| イAです | 礼貌肯定；过去「かったです」，否定「くないです」 | この本はおもしろいです。／这本书很有趣。 |
| ナAです | 礼貌肯定；修饰名词用「な」 | この町は静かです。静かな町です。／这座城安静；安静的城。 |
| イAくて／ナAで | 并列性质或原因 | 安くて便利です。静かで安全です。／便宜且方便；安静又安全。 |
| イAくなる／ナA・Nになる | 自然变化“变得／成为” | 日本語が上手になりました。／日语变好了。 |
| イAくする／ナA・Nにする | 人为改变／决定选择 | 音を小さくしてください。これにします。／请调小声音；选这个。 |
| Nは～がイA／ナA | 整体主题＋局部主语 | 象は鼻が長いです。／大象鼻子长。 |
| Nが好き／嫌い／上手／下手 | 喜好与能力对象用「が」 | 妹は料理が上手です。／妹妹擅长做饭。 |

## 比较、程度与数量

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| N1はN2より～ | A 比 B…… | 電車はバスより速いです。／电车比公交快。 |
| N1とN2とどちらが～か | 两者哪个更…… | 犬と猫とどちらが好きですか。／猫狗更喜欢哪个？ |
| Nの中で～が一番 | 某范围内最…… | 果物の中で桃が一番好きです。／水果中最喜欢桃。 |
| Nほど～ない | 不如……；N5 后期常见 | 今日は昨日ほど寒くないです。／今天没昨天冷。 |
| 数量词＋V | 数量词通常放在动词前，不加「の」 | りんごを三つ買いました。／买了三个苹果。 |
| 时间段＋V | 持续时长不用「に」 | 毎日二時間勉強します。／每天学两小时。 |
| 时间段＋かかる | 花费时间／金钱 | 駅まで十分かかります。／到车站要十分钟。 |
| ぐらい／くらい | 大约；数量后 | 三十分ぐらい待ちました。／等了约三十分钟。 |
| だけ | 仅仅、只有；中性限定 | 水だけ飲みました。／只喝了水。 |

## 时间与频率

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| 时间に | 精确时间点 | 六時半に起きます。／六点半起床。 |
| NからNまで | 从……到…… | 月曜日から金曜日まで働きます。／周一工作到周五。 |
| N1からN2まで＋时间 | 从 A 到 B 用时 | 家から学校まで三十分かかります。／家到学校半小时。 |
| いつも／よく／時々／あまり～ない／全然～ない | 频率由高到低 | 忙しくて、あまりテレビを見ません。／忙，不怎么看电视。 |
| もうVた | 已经做了 | 宿題はもう終わりました。／作业已经做完了。 |
| まだVていない | 还没做 | 昼ご飯はまだ食べていません。／还没吃午饭。 |

## 名词修饰与说明

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| 普通形＋N | 小句修饰名词；小句主语常用「が」 | 母が作った料理はおいしいです。／妈妈做的菜很好吃。 |
| V辞書＋こと | 动词名词化，偏抽象／规则 | 日本語を話すことは楽しいです。／说日语很快乐。 |
| V普通形＋の | 名词化，偏具体可感知事件 | 写真を撮るのが好きです。／喜欢拍照。 |
| ～んです／のです | `V／イA普通形；ナA／N＋な`；说明背景、理由 | どうして遅れたんですか。電車が止まったんです。／为何迟到？因为电车停了。 |
| どんなN | 询问性质类别 | 京都はどんな町ですか。／京都是怎样的城市？ |
| どう／どうして | 怎样／为什么 | この漢字はどう読みますか。／这个汉字怎么读？ |
