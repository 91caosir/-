# N5-01 判断、指示、存在与助词

## 判断与疑问

| 句型            | 接续／意义                 | 例句                           |
| ------------- | --------------------- | ---------------------------- |
| NはNです         | A 是 B；「は」提示主题         | 私は留学生です。／我是留学生。              |
| NはNではありません    | 礼貌否定；口语也说「じゃありません」    | 田中さんは先生ではありません。／田中不是老师。      |
| NはNでした        | 礼貌过去肯定                | 昨日は休みでした。／昨天休息。              |
| NはNではありませんでした | 礼貌过去否定                | 先週は暇ではありませんでした。／上周不空。        |
| ～か            | 句末表示疑问；礼貌问句一般不用问号也成立  | これは辞書ですか。／这是词典吗？             |
| Nも            | “也”；取代「は／が／を」         | 私も一年生です。／我也是一年级学生。           |
| NのN           | 所属、属性、内容；后一个名词可在语境中省略 | これは日本語の本です。私のです。／这是日语书，是我的。  |
| N1かN2         | 二选一，“A 还是 B”          | 試験は月曜日ですか、火曜日ですか。／考试是周一还是周二？ |
| ～ね／～よ         | ね：确认、共感；よ：告知对方未知信息    | きれいですね。明日は休みですよ。／真漂亮啊。明天放假哦。 |

## 指示词与连体词

| 系列 | 近说话人 | 近听话人 | 远离双方 | 疑问 | 用法 |
|---|---|---|---|---|---|
| 事物 | これ | それ | あれ | どれ | 单独作名词 |
| 连体 | この | その | あの | どの | 后面必须接名词 |
| 场所 | ここ | そこ | あそこ | どこ | 地点 |
| 方向／礼貌场所 | こちら | そちら | あちら | どちら | 方向、人或礼貌地点 |

例：この傘はだれのですか。／这把伞是谁的？　駅はあちらです。／车站在那边。

## 存在与位置

| 句型 | 接续／意义 | 例句 |
|---|---|---|
| Nがある | 无生命物存在／拥有 | 机の上に本があります。／桌上有书。 |
| Nがいる | 人、动物存在 | 教室に学生がいます。／教室里有学生。 |
| 场所にNがある／いる | 「に」标存在地点 | 公園に猫がいます。／公园里有猫。 |
| Nは场所にある／いる | 已知事物的位置；主题用「は」 | 銀行は駅の前にあります。／银行在车站前。 |
| N1の位置词にN2 | 上／下／前／後ろ／中／外／隣／近く／間 | 箱の中に写真があります。／盒子里有照片。 |

## 基础格助词

| 助词  | 核心功能                  | 例句                                |
| --- | --------------------- | --------------------------------- |
| は   | 主题、对比；读作「わ」           | 私はコーヒーは飲みますが、お酒は飲みません。／咖啡我喝，酒不喝。  |
| が   | 主语、新信息、疑问词的回答、能力／喜好对象 | だれが来ますか。李さんが来ます。／谁来？小李来。          |
| を   | 他动词的宾语；离开／经过场所        | パンを食べます。公園を歩きます。／吃面包；走过公园。        |
| に   | 时间点、到达点、存在点、对象、目的     | 七時に学校に行きます。／七点去学校。                |
| へ   | 移动方向；读作「え」            | 日本へ来ました。／来到了日本。                   |
| で   | 动作场所、手段、材料、范围         | 図書館で日本語で手紙を書きます。／在图书馆用日语写信。       |
| と   | 共同者、完全列举、引用           | 友達と話します。パンと牛乳を買います。／和朋友说话；买面包和牛奶。 |
| や   | 不完全列举，常与「など」呼应        | 机に本やノートなどがあります。／桌上有书、笔记本等。        |
| から  | 起点、来源；“从”             | 九時から勉強します。／从九点开始学习。               |
| まで  | 终点、界限；“到”             | 五時まで働きます。／工作到五点。                  |
| も   | 也；疑问词＋も＋否定＝全盘否定       | 何も食べませんでした。／什么也没吃。                |
| の   | 所属、属性；代替已知名词          | 日本の会社です。赤いのをください。／日本公司；请给我红的。     |
| か   | 疑问；疑问词＋か＝某个／某人        | 何か飲みますか。／喝点什么吗？                   |

## 易错点

- 「は」不是主格标记；一句中可同时出现「私は日本語が好きです」。
- 具体时刻用「に」，相对时间「今日、明日、毎日、先週」通常不加「に」。
- 移动目的用 `Vます＋に`：本を買いに行きます。这里的「に」不是宾语。
