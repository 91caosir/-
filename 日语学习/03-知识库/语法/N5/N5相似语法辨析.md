# N5相似语法辨析

| 对比 | 区别 | 最小对比例 |
|---|---|---|
| は vs が | は设主题／对比；が标新信息、焦点或从句主语 | 私は学生です。／だれが学生ですか。私が学生です。 |
| に vs で | に是存在／到达点；で是动作发生处 | 教室に先生がいます。／教室で先生が話します。 |
| に vs へ | に强调到达点；へ强调方向 | 日本に着きました。／日本へ向かいます。 |
| と vs や | と列举全部；や只举例 | 本とノートを買った。／本やノートを買った。 |
| ませんか vs ましょう | 前者询问、较委婉；后者直接提议 | 行きませんか。／行きましょう。 |
| てから vs た後で | てから强调完成 A 才 B；後で是一般时间先后 | 食べてから薬を飲む。／食べた後で散歩する。 |
| ないで vs なくて | ないで＝不做 A 而 B；なくて多为原因／并列 | 傘を持たないで出た。／お金がなくて買えない。 |
| たい vs ほしい | たい想做动作；ほしい想要东西 | 日本へ行きたい。／切符がほしい。 |
| から vs ので | N5 先掌握から；ので更客观委婉，详见 [[N4-01原因时间条件]] | 疲れたから休む。／疲れたので休みます。 |
| こと vs の | こと偏抽象、规则；の偏具体、感知 | 読むことは大切だ。／読むのが速い。 |
