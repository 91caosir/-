# N5-02 动词活用与基础句型

变形规则见 [[用言活用总表]]。

## ます形系统

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| Vます／ません | 礼貌非过去肯定／否定；也表习惯、将来 | 毎朝走ります。明日は走りません。／每天早晨跑；明天不跑。 |
| Vました／ませんでした | 礼貌过去肯定／否定 | 昨日勉強しました。／昨天学习了。 |
| Vませんか | 委婉邀请，对方可拒绝 | 一緒に昼ご飯を食べませんか。／一起吃午饭吗？ |
| Vましょう | 提议“一起……” | 少し休みましょう。／休息一下吧。 |
| Vましょうか | 主动提议帮忙／征求共同决定 | 荷物を持ちましょうか。／我来拿行李吧？ |
| Vます＋に行く／来る／帰る | 移动目的 | 図書館へ本を借りに行きます。／去图书馆借书。 |
| Vたい | `Vます＋たい`，第一人称愿望；按イA活用 | 日本で働きたいです。／想在日本工作。 |
| Nがほしい | 想要某物；「ほしい」按イA活用 | 新しい辞書がほしいです。／想要新词典。 |

## て形系统

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| Vて、V | 动作先后或并列 | 朝ご飯を食べて、学校へ行きます。／吃早饭后去学校。 |
| Vてください | 礼貌请求对方做 | ここに名前を書いてください。／请在这里写名字。 |
| Vないでください | 请求不要做 | この写真を見ないでください。／请不要看这张照片。 |
| Vてもいい | 许可“可以……” | ここに座ってもいいです。／可以坐这里。 |
| Vてはいけない | 禁止“不可以……”；口语「ちゃいけない」 | ここで写真を撮ってはいけません。／这里不能拍照。 |
| Vている | 正在进行、持续状态、习惯 | 今本を読んでいます。東京に住んでいます。／正在读书；住在东京。 |
| Vてから | 做完 A 再 B，先后明确 | 手を洗ってから、食べます。／洗手后再吃。 |
| Vても | 即使／无论 | 雨が降っても行きます。／即使下雨也去。 |
| Vて、イAくて、ナA／Nで | 原因或并列连接；后句不可常接强命令 | 頭が痛くて、学校を休みました。／头痛，所以没去学校。 |

## ない形、辞书形与た形

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| Vない | 普通体否定 | 肉は食べない。／不吃肉。 |
| Vないで | 不做 A 而做 B／在不做 A 的状态下 | 朝ご飯を食べないで出かけました。／没吃早饭就出门了。 |
| Vなければならない | 必须；`ない → なければ` | 明日早く起きなければなりません。／明天必须早起。 |
| Vなくてもいい | 不做也可以／不必 | 明日は来なくてもいいです。／明天不用来。 |
| V辞書＋ことができる | 能够；能力或条件允许 | ここで泳ぐことができます。／可以在这里游泳。 |
| V辞書＋前に | 做 A 之前做 B；Nの前に | 寝る前に歯を磨きます。／睡前刷牙。 |
| Vた＋後で | 做 A 之后；Nの後で | 授業が終わった後で質問します。／下课后提问。 |
| Vたことがある | 曾经有过某经验；不用于昨天等具体一次 | 富士山に登ったことがあります。／爬过富士山。 |
| VたりVたりする | 列举代表性动作；最后用「する」决定时态 | 日曜日は掃除したり、映画を見たりします。／周日打扫、看电影等。 |

## 普通体与引用

| 句型 | 接续／语感 | 例句 |
|---|---|---|
| 普通形＋と思う | 我认为／推测；N／ナA肯定接「だ」 | 明日は雨が降ると思います。／我想明天会下雨。 |
| 普通形＋と言う | 直接或间接引用；N／ナA肯定接「だ」 | 先生は「休みます」と言いました。／老师说“休息”。 |
| 小句＋から | 主观原因“因为……” | 寒いですから、窓を閉めます。／因为冷，所以关窗。 |
| 小句＋が／けど | 转折或铺垫，“但是／那个……” | 行きたいですが、時間がありません。／想去，但没时间。 |
| V辞書＋つもり | 打算；否定为「Vないつもり」 | 来年日本へ行くつもりです。／打算明年去日本。 |

> [!warning]
> 「たい／ほしい」直接陈述第三人称愿望不自然。初级先用「李さんは日本へ行きたいと言っています」。
